# ChatGPT Desktop Application - short recording notes

Deck: `chatgpt-desktop-application.pptx` (5 slides), built by
`build_chatgpt_desktop_application.py`.

## Purpose

This short deck focuses on the distinctive benefit of the desktop application: ChatGPT
can work with a selected local folder and place finished files back on the computer.
Computer Use gets its own follow-on lesson.

## Speaking notes

1. **ChatGPT Desktop Application**
   - The desktop app brings ChatGPT next to the files and applications involved in the work.
2. **A workspace beside your local files**
   - Open a folder and ask ChatGPT to use the files inside it.
   - It can read source material, create a deliverable and save the result beside the source.
3. **Local access starts with a boundary you choose**
   - The selected folder defines the working context.
   - File edits and application access still follow permissions and approvals.
4. **The distance between asking and doing gets shorter**
   - You spend less time uploading copies, downloading outputs and putting files back in the right place.
   - A broad folder can expose more context than the task needs, so choose a narrow location.
5. **Live handoff**
   - Open a small folder, ask ChatGPT to read one file, create or edit an output and review the saved result.
