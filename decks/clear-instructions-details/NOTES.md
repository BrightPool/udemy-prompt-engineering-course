# Writing Clear Instructions - detailed instructions recording notes

Deck: `clear-instructions-details.pptx` (5 slides), built by
`build_clear_instructions_details.py`.

## Purpose

This lesson shows how audience, purpose, required content and output shape turn a
vague request into a brief that can be checked.

## Speaking notes

1. **Writing Clear Instructions**
   - Detail matters when it changes what success looks like.
2. **Detail defines what a good answer must contain**
   - Compare a generic product update with a request that names audience and content.
3. **Four details make the request checkable**
   - Audience, purpose, required content and output shape form a compact brief.
4. **Clear criteria make revision faster**
   - Feedback can point to a missed requirement instead of relying on taste.
5. **Live handoff**
   - Add only the details that materially change one ChatGPT response.
