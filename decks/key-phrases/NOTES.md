# Key Phrases To Add To Your Prompts - recording notes

Deck: `key-phrases.pptx` (6 slides), built by `build_key_phrases.py`.

## Purpose

Teaches short, reusable phrases that give the model a finish line: a minimum size, an
objective to reach, a length of time to keep working, or a review step afterwards.

## Speaking notes

1. **Key Phrases To Add To Your Prompts**
   - Short, reusable phrases that set how much, how long and when to stop.
2. **A phrase that sets the finish line**
   - Meeting notes to follow-up email; the floor and the objective are highlighted.
3. **Four phrase families**
   - Floors (how much), objectives (when to stop), time (how long), review (who checks).
   - Review is only a preview here; it has its own lecture, Adversarial Review of Outputs.
4. **Why it matters - checkable beats vague**
   - "At least 200 rows" can be verified; "make it good" cannot.
   - Be honest about limits: floors can invite padding, and "work for 2 hours" only means
     something in an agent such as Codex that keeps working. A chat reply ends when it ends.
5. **Cheat sheet**
   - Four copyable templates. Leave this on screen for a beat.
6. **Live handoff**
   - Add a floor to an email, set an objective, ask for a review.
